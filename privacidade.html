Política de Privacidade

Como os dados são tratados nesta versão demonstrativa do RotaAcessível.

1. Finalidade

O projeto permite pesquisar, cadastrar e avaliar estabelecimentos quanto aos recursos de acessibilidade informados pelos usuários.

2. Dados tratados

Ao cadastrar um local, são registrados nome, categoria, endereço, recursos de acessibilidade e foto opcional. Ao avaliar, são registrados nota e comentário opcional. Esta versão não solicita cadastro de conta ou identificação pessoal.

3. Armazenamento

Os dados cadastrados e as avaliações são armazenados no localStorage do navegador usado para acessar o site. Não há servidor, banco de dados remoto nem sincronização entre dispositivos nesta demonstração.

4. Compartilhamento e cuidados

Não envie fotos ou comentários com informações pessoais de terceiros sem autorização. Os dados aparecem apenas para quem usa o mesmo armazenamento local do navegador.

5. Controle dos dados

O usuário pode remover os dados locais limpando o armazenamento do site nas configurações do navegador. Isso também apaga cadastros e avaliações feitos nesta instalação.

6. Natureza do projeto

Esta política descreve o protótipo acadêmico atual. Antes de publicar o sistema em produção, será necessário revisar os fluxos de dados, os responsáveis pelo tratamento e os canais de atendimento conforme a LGPD (Lei nº 13.709/2018).
